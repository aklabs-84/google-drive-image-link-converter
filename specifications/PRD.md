# 제품 요구사항 정의서 (PRD) - GDrive Linker

## 1. 개요
GDrive Linker는 구글 드라이브에 저장된 이미지를 블로그, 노션, 깃허브 및 개인 웹사이트와 같은 외부 플랫폼에서 쉽게 사용할 수 있도록 돕는 웹 기반 유틸리티입니다. 표준 구글 드라이브 공유 링크를 직접 이미지 URL, HTML `<img>` 태그 및 마크다운(Markdown) 문법으로 즉시 변환해 줍니다.

## 2. 배경 및 목표
구글 드라이브의 기본 "공유" 링크는 원본 이미지 파일이 아닌 미리보기 페이지로 연결됩니다. 이로 인해 이미지의 `src` 속성이나 마크다운 이미지 문법에서 정상적으로 작동하지 않는 문제가 발생합니다.
**목표**: 사용자가 호환 가능한 링크를 즉시 생성할 수 있도록 심플하고 빠르며 미려한 인터페이스를 제공하는 것입니다.

## 3. 타겟 사용자
- 깃허브(GitHub)나 노션(Notion)을 사용하는 개발자 및 테크 블로거.
- 구글 드라이브를 자산 호스팅 용도로 사용하는 콘텐츠 크리에이터.
- HTML 지원 환경에 구글 드라이브 이미지를 삽입해야 하는 모든 사용자.

## 4. 핵심 기능
- **즉각적인 링크 추출**: 다양한 구글 드라이브 URL 형식(file/d, open?id 등)에서 파일 ID를 자동으로 감지하고 추출합니다.
- **다양한 변환 옵션**:
    - **직접 링크 (Direct URL)**: 표준 직접 다운로드 링크.
    - **추천 링크 (Bypass Thumbnail)**: 마크다운에서 더 안정적으로 작동하고 보안 검사를 우회하는 구글 Thumbnail API 기반 링크.
    - **HTML 태그**: 바로 사용 가능한 `<img src="...">` 스니펫.
    - **마크다운 태그**: 바로 사용 가능한 `![이미지](...)` 스니펫.
- **이미지 미리보기**: 변환된 링크의 유효성을 즉시 확인할 수 있는 대화형 미리보기 기능.
- **원클릭 복사**: 생성된 모든 링크와 태그를 빠르게 복사할 수 있는 버튼.
- **사용 가이드**: 구글 드라이브 권한 설정("링크가 있는 모든 사용자")방법을 안내하는 모달창.
- **주의 사항 섹션**: 파일 권한 및 잠재적 제한 사항에 대한 안내.

## 5. 사용자 인터페이스 및 경험 (UI/UX)
- **현대적인 디자인**: 깔끔한 화이트/슬레이트 배경에 블루 포인트 컬러를 사용한 전문적인 느낌.
- **반응형 레이아웃**: 데스크탑, 태블릿, 모바일에서 원활한 사용 경험 제공.
- **사용자 피드백**: 링크 복사 시 시각적 확인 메시지("Copied!") 제공.
- **접근성**: 명확한 라벨과 직관적인 아이콘(FontAwesome) 사용.

## 6. 성공 지표
- 사용자가 5초 이내에 링크 변환을 완료할 수 있음.
- 추천 링크(Thumbnail Bypass) 사용 시 이미지 깨짐 현상 제로화.
- 높은 접근성 및 모바일 반응성 유지.
